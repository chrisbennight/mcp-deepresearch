# Security

Do not include credentials or confidential research material in public issues.
Use GitHub's private vulnerability reporting if enabled; otherwise contact the
repository owner privately before disclosing an exploitable vulnerability.

The initial deployment target is a trusted single operator behind authenticated
infrastructure, not an anonymous internet service or hosted multi-tenant product.
Source pages and attachments are untrusted data. Tool authority must be constrained
independently of prompts. Routine logs must exclude credentials, prompts, and source
bodies. Private deployment configuration does not belong in this repository.
